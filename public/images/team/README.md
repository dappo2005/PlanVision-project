## Format Foto
- Gunakan nama dan ekstensi persis seperti daftar di atas, kecuali path pada
  komponen frontend juga diperbarui.
- Ukuran disarankan: 400x400 pixels (atau lebih besar dengan rasio 1:1)
- Ukuran file: Maksimal 2MB per foto

## Catatan
- Jika foto tidak ditemukan, sistem akan menampilkan inisial avatar sebagai fallback
- Foto akan ditampilkan dalam bentuk lingkaran (circular) dengan border putih
- Pastikan foto memiliki kualitas yang baik untuk tampilan yang optimal
